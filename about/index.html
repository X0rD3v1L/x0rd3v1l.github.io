About.

I’m Benarjee Sambangi — @X0rD3v1L across the internet. I write Rust for a living and blockchain for fun, with a trail of performance wins, squashed bugs, and shipped products across fintech, DeFi, and healthcare.

Currently at Mphasis as a Senior Software Engineer, where I build high-performance financial systems in Rust — from a PyO3-powered calculation engine to a risk monitoring platform that slashed trade data retrieval latency by ~30%. I wrangle FIX protocol messages, architect Redis-backed batch pipelines, and write Python automation scripts that keep end-of-day financial workflows running without anyone waking up at 3am.

Before that, I was deep in the Solana ecosystem at Chingari — shipping a token launchpad with Rust + Anchor, patching a critical security vulnerability, and trimming staking API latency by ~20%. Earlier still, I built smart contracts and backend modules for the USBD stablecoin protocol on Arch Network at BIMA, cutting contract execution time by ~25%.

On the frontend side, I’ve revamped payroll dashboards, automated 1K+ monthly reports, and published internal npm packages that killed ~3K lines of redundant code across three projects. I don’t just write code — I clean up after it too.

I recently completed the Polkadot Blockchain Academy’s Protocol Builders Program (Lisbon, 2026), adding substrate and cross-chain protocol design to my toolkit.

My stack: Rust · Python · JavaScript · Rocket · PostgreSQL · Redis · ReactJS · Solana · Anchor

When I’m not in the terminal, I’m probably on a road trip, looking for the next interesting place (or problem).
